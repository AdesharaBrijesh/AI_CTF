What is this?

Indirect prompt injection (OWASP LLM01). When an assistant processes untrusted content — a pasted document, a fetched web page, an email, a PDF — that content arrives in the same channel as its real instructions. Text inside the data can therefore act as a command. This is a safe, simulated target; no real systems are touched.
